JEV is a generalized classification model.

- Decision-making speed is very fast.
- Very low cost.
- We can ask multiple questions.
- Provides a confidence score.
- Cannot hallucinate by design.

*Software needs System 1 thinking, but we keep building System 2 thinking.*

### Use Cases

1\) AI Agents

- Which tool should be used?
- Which model should be selected?
- Is this step safe?
- Every small decision can be checked quickly and cheaply.

2\) Business Operations

- Support triage: If an email comes in, which team should it be forwarded to?
- Claims: Should a refund be issued or not?
- Invoices: Is an invoice real or fake?
- Lead scoring: Is this lead likely to generate revenue or not?

3\) Trust and Safety

- Moderation: Remove inappropriate comments in real time.
- Fraud detection
- Spam detection
- Jailbreak detection: Determine whether an incoming prompt is attempting a jailbreak or prompt injection.

All this work is done before the LLM comes into the picture.
